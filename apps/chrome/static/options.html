Connection

Pick a provider and model. xgoose runs your prompts against whichever endpoint you choose — your key, your bill, your control.

Skills

Bundled skills ship with the extension. Custom skills are yours — they live in extension storage and inject into the page MAIN world from a Blob URL. Disable any skill you don't want to auto-attach when its URL pattern matches. Visit a raw .xgs.js URL and the install page opens automatically.

Edit skill

Skills are a single .xgs.js file (Tampermonkey-style header + JS body). Edit the source below — the header is parsed and validated on save, the body is bundled at install time. See SKILL_AUTHORING.md for the format.

The // ==XGooseSkill== … // ==/XGooseSkill== header drives matches / namespace / version. After save, navigate to a matching URL (or reload) for the skill to activate.

Advanced

Sensitive header values (Authorization, Cookie, …) are always redacted before being shown to the model — this protection is on by default and cannot be turned off.

About

xgoose-extension-chrome is the Chrome MV3 host for the xgoose agent. Built on @xgoose/core + @xgoose/page-controller + @xgoose/ui.

On strict-CSP sites the js_exec tool may fail to inject the page bridge. Tools that don't need DOM access still work.
