How to write your first skill
  1. Start with a single .xgs.js file. Set a unique name, namespace and version; set @match to the website you want.
  2. Add a clearly described function with an input schema. Start with a read-only action and keep results bounded.
  3. Review the source in the installer, click Install, then open the matching website to test.
  4. To revise it, open Settings → Skills → Manage installed skills → Edit. Local files and pasted source need no publishing or xgoose account.

Common questions and setup problems

Common questions and setup problems
  • Why did it read my login page or email? Open the website you want to research and ask again there. Installed skills only activate on matching websites.
  • Why can’t it use a website skill? Built-in skills work without User Scripts. For installed, edited or online-updated scripts, enable Allow User Scripts using the highlighted guide above, then return and retry.
  • Did it read the entire thread? A preview or summary may cover only part. Ask for the actual range and for remaining replies to be read in batches.
  • Did the search succeed? A completed script can still contain failed searches. Failed to fetch or a rate limit means the assistant needs to state what evidence is missing.
