# Store artwork, version 0.2.4

The owner requested English promotional renders rather than Chinese screenshots.

Palette: ink #24203B, xgoose violet #7357E8, lavender #F5F3FC,
Chrome blue #1769E0, beak orange #FFAE57, white #FFFFFF.
Type: Avenir Next for editorial headings; Helvetica Neue for the product panels;
Menlo for the real starter-code excerpt.

Layout: large left-aligned benefit and one browser-shaped product scene. Vary
scene composition by function. Use horizontal rules for actual settings groups,
sequence numbers only for the permission SOP, and one orange brand accent.

The first concept was revised to remove generic floating decorative cards and
gradient backgrounds. Chrome tabs, page context, source links and the distinctive
existing goose icon carry the identity. The existing product logo is unchanged.

These are labelled feature illustrations, not screenshots of customer sessions.
Research replies are illustrative, not model performance evidence. No real email,
API key, quota balance or private transcript appears. The permission image uses
the actual Chrome details page included in the product guide; blue highlights
identify the real switch. Account trial claims remain subject to availability
and account limits. Skill controls and settings are simplified for readability.

Run `node scripts/render-store-assets.mjs` to reproduce the five 1280×800 store
images, 440×280 small tile, 1400×560 marquee and 1200×630 social image. The local
artwork-preview.png is a review sheet, not a store upload. Previous store assets
are backed up in previous-0.2.3/ so the draft replacement is reversible.

Final owner selection: keep all three original screenshots and both promo tiles;
add only 01-research.png and 03-images.png in gallery positions one and two.
