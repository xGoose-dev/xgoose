xgoose researches the current website with 59 packaged skills. Page reading and built-in skills work without optional User Scripts. BYOK chat does not require a xgoose account. Hosted AI and optional shared Exa search require an email-confirmed account; Exa public searches deduct their actual cost from the same account credit.

Version 0.5.3 fixes Discord taking keyboard focus while typing in the xgoose panel. It updates 29 existing packaged skills and adds Douban, WeRead, Bilibili, Google Flights and Google Hotels. The new readers reuse the existing website session or public endpoints and require no additional extension permissions. Existing notification settings remain off by default.

Hosted transcripts retain complete tool inputs/results and notification receipts for 90 days, with credential redaction and audited administrator access. BYOK transcripts stay local. Optional usage analytics excludes conversation content and credentials. Source and reproducible build instructions are public on GitHub. No production keys are included in the extension.
