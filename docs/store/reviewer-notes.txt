xgoose is a current-website AI assistant with 34 packaged website skills. Built-in skills and page reading work without Allow User Scripts. Optional community, edited or updated scripts require the browser's User Scripts permission. Settings and onboarding provide setup links. AI uses an email-confirmed Hosted account or the reviewer's own Gemini/OpenAI-compatible API key. BYOK needs no xgoose account. No private production credentials are included.

Amex tools run only for the active task; on-demand SOPs do not perform automatic account actions. No new permissions.
