xgoose researches the current website with 37 packaged skills. Page reading and built-in skills work without optional User Scripts. BYOK chat does not require a xgoose account. Hosted AI and optional shared Exa search require an email-confirmed account; Exa public searches deduct their actual cost from the same account credit.

Version 0.4.4 adds site-first public search fallback and optional agent notifications. Notifications are off by default, stored per browser, and the optional notifications permission is requested only when the user enables the setting. An enabled agent can send a brief alert; a successful task on an inactive page can also notify. Clicking focuses its source tab. No notification is sent for a failed, cancelled or waiting task. Safari/iOS does not enable browser notifications.

Hosted transcripts retain complete tool inputs/results and notification receipts for 90 days, with credential redaction and audited administrator access. BYOK transcripts stay local. Optional usage analytics excludes conversation content and credentials. Source and reproducible build instructions are public on GitHub. No production keys are included in the extension.
