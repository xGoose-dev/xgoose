xgoose is a current-website AI assistant with 34 packaged website skills. Built-in skills and page reading work without Allow User Scripts. Optional community, edited or updated scripts require the browser's User Scripts permission. Settings and onboarding provide setup links. AI uses an email-confirmed Hosted account or the reviewer's own Gemini/OpenAI-compatible API key. BYOK needs no xgoose account. No private production credentials are included.

0.4.2 improves optional usage analytics with browser/OS/language/screen metadata and measured foreground interaction time. Hidden tabs, closed chat panels and idle periods are excluded. Analytics account tokens are renewed through the existing sign-in coordinator, with durable retries and the existing opt-out controls. No new browser permissions. Conversation contents, page URLs and credentials are not included in usage analytics.

Hosted transcript retention is 90 days with credential redaction and audited administrator access. BYOK chats stay local. Usage analytics is optional. Source and build instructions are public on GitHub.
