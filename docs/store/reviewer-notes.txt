xgoose is a current-website AI assistant with 34 packaged website skills. Built-in skills and page reading work without Allow User Scripts. Optional community, edited or updated scripts require the browser's User Scripts permission. Settings and onboarding provide setup links. AI uses an email-confirmed Hosted account or the reviewer's own Gemini/OpenAI-compatible API key. BYOK needs no xgoose account. No private production credentials are included.

0.3.6 fixes Hosted session renewal during running tasks. The background worker reads current credentials for each Hosted request, shares renewal across tabs and retries a rejected HTTP 401 once. Completed tools are not replayed. Logout and account changes take precedence over stale renewals. If recovery fails, the panel clearly states that listening/actions have stopped and preserves the conversation for sign-in and explicit continuation. BYOK providers keep their own credentials and behavior. No new permissions.

Hosted transcript retention is 90 days with credential redaction and audited administrator access. BYOK chats stay local. Usage analytics is optional. No new permissions were added. Source and build instructions are public on GitHub.
