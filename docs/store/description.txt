xgoose brings an AI assistant to the page you are already reading. Open the floating panel, ask a question, and use website skills to search and read relevant content without losing sight of the page.

Research with sources
Use installed skills to search a forum and read its topics. Follow links in the answer back to the original sources, compare different experiences, and ask follow-up questions. Check source material before relying on an answer.

Choose your tools
Install website skills from xgoose.org and review their source. Enable or disable installed skills, edit their source, and choose when to update. JavaScript tools and skills can read or change the current page using its session; install only skills you trust.

Connect your own AI
Bring an OpenAI-compatible endpoint, including LiteLLM, or a Gemini API key. BYOK works without an xgoose account. Hosted xgoose uses Luna and requires a verified account, available credit and explicit consent to conversation storage. Trial availability is shown in your account when the campaign is open.

Sign in from the extension
Enter your email in settings and click the confirmation link in your inbox. Your account is created after confirmation. No password or separate website registration is needed.

Set up once
Requires Chrome 138 or newer. Open chrome://extensions, select xgoose Details, and enable Allow User Scripts to use JavaScript tools and installed skills. Visit a supported page, open the floating panel, and ask a question.

Stay in control
Stop a run at any time. xgoose works on the current page: refreshing, navigating away or closing it ends the active run. Saved chat history remains available locally. Disabling a skill prevents new calls but cannot undo earlier requests or page changes; refresh the page if necessary.

Conversation privacy
Hosted Luna saves full messages and actual tool inputs and outputs for 90 days after your explicit consent. BYOK conversation upload is off by default and can be enabled separately after signing in. View, export and delete uploaded conversations from your account. Staff can read a specific conversation only with your authorization.
