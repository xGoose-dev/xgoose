xgoose 是当前网页上的 AI 助手。打开悬浮聊天面板，就能围绕正在浏览的页面提问，使用网站技能搜索、阅读和整理内容，并通过来源链接回到原文核实。

带着来源做研究
在支持的网站上搜索帖子、阅读正文与回复、比较不同用户的经验，再继续追问。支持的 Discourse 论坛可按顺序分批读取回复，显示实际覆盖范围和来源链接。AI 回答可能有误，请核实重要信息。

34 个内置网站技能，安装后即可使用
内置技能包括美卡论坛、Hacker News、Reddit、V2EX、NGA、微博等。V2EX、NGA、微博和 Reddit 提供“概括当前帖子”“热帖”“新帖”“随机发现”等快捷操作；中文网站使用中文按钮名称。微博搜索可直接在 weibo.com 使用。

在 NGA，可选择额外的图片总结操作，将最多三张帖子图片发送给所选的、支持图片的模型，并保留原始楼层链接。普通帖子总结只读取文字。搜索条件、用户资料、回复和分页等功能因网站而异，仍受网站登录状态和接口访问限制约束。

使用托管 AI，或连接自己的服务
新安装默认使用 Haiku 5.5。选择 xgoose Hosted AI，使用邮箱登录后即可使用账号中的可用额度，无需复制 API Key。托管模型由账号提供，试用活动开放时会在账号中展示可领取的额度；可用模型、额度和访问条件以实际账号状态为准。

也可以在设置中选择 BYOK，使用自己的 Gemini API Key，或连接 OpenAI 兼容接口（包括 LiteLLM）。BYOK 无需注册 xgoose 账号。设置中提供连接测试。

邮箱登录，无需密码
在插件设置中输入邮箱，点击收件箱中的确认链接即可创建并登录账号，不必另外前往网站注册。完成后，请回到想使用的网站，在对应标签页打开 xgoose；网站技能会根据当前页面匹配。

基础功能无需开启 User Scripts
需要 Microsoft Edge 138 或更新版本。读页面和随插件发布的内置技能可以直接使用，无需开启 Allow User Scripts（允许用户脚本）。

如果要安装社区技能、编辑技能、使用在线更新后的脚本或自定义 JavaScript，请打开 edge://extensions，进入 xgoose 的详细信息并开启 Allow User Scripts。设置和相关聊天错误提供快捷链接与图文步骤。使用内置技能的网站时，权限提醒保留在设置中。

技能安装与更新
在 xgoose.org 发现更多技能，也可以从本地文件或 URL 导入，查看源码后再安装。在设置中启用、停用或编辑技能。xgoose 每天检查支持更新的目录技能；有新版本时显示提醒，由你查看版本、匹配网站和源码后决定是否更新。替换有本地修改的技能前会提示。

JavaScript 工具和技能可以通过当前登录会话读取或修改网页，请只安装你信任的技能。停用技能会阻止后续调用，但无法撤销之前发出的请求或页面改动，必要时请刷新页面。

按你的习惯使用
界面支持中文、英文和西班牙语，默认跟随浏览器语言。在入门页面选择语言，会同时设置界面和偏好回复语言；之后可在设置中分别调整。选择 Automatic 时，不额外限定 AI 回复语言；明确选择语言后，将作为默认回复偏好，对话中提出的语言要求优先。

点击减号可最小化聊天，保留草稿与对话，正在生成的回复会继续。你可随时停止任务；刷新、跳转或关闭当前网页会结束正在执行的任务。

长对话自动整理上下文
上下文容量随所选模型调整，包括支持百万 token 上下文的托管模型。Context 指示器区分当前上下文占用和累计用量；发送前的本地统计是估算值。接近模型上限时，自动压缩上下文并预留回复空间，方便继续对话，完整聊天历史仍保存在本地。

支持图片对话
每条消息最多附加三张 PNG、JPEG 或 WebP 图片，也可以直接粘贴图片。在发送前预览或移除附件。图片先在本地调整尺寸，再发送给你选择的、支持图片的模型。附件图片保留在本地对话历史中；诊断记录包含附件元数据，不包含图片本体。

隐私与使用统计
使用 Hosted AI 时，完整消息以及工具的实际输入、输出和错误会按隐私说明保存 90 天，并进行凭据脱敏。云端对话诊断记录包含使用网站的域名，仅管理员可读取，每次读取都有审计记录。BYOK 对话保留在本地，插件不会上传这些对话。

可选的使用统计记录设置步骤、操作结果和耗时；登录后的事件可能关联到你的账号。可随时在设置中关闭。使用统计不包含聊天消息、密钥或完整网页地址。

入门页面重点介绍邮箱登录、可选的 User Scripts 设置和推荐体验的网站。技能安装、编写与排错指南位于独立的高级帮助页面；在 xgoose.org 上也能通过内置指南了解这些操作。
